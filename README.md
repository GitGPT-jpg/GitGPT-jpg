## Engineering Philosophy | 工程理念

### EN
- **System over feature**: prioritize architecture, extensibility, and maintainability.
- **Workflow over prompt**: build reliable pipelines, not one-off prompt tricks.
- **Determinism + intelligence**: combine rule-based control with model-based reasoning.
- **Deliverability first**: optimize for practical deployment, iteration speed, and business impact.
- **Measure and evolve**: treat every agent workflow as an engineering system to observe and improve.

### 中文
- **系统优先于功能**：优先考虑架构、可扩展性与可维护性。
- **工作流优先于提示词**：构建稳定流水线，而非一次性 prompt 技巧。
- **确定性 + 智能性**：将规则控制与模型推理结合。
- **交付优先**：面向可部署、可迭代、可产生业务价值的方案。
